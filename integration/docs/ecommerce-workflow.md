## 第1轮：目标与任务书

### 发送的 prompt

我们是淘宝新店“青禾桌面”，准备上架一款79元的铝合金折叠电脑支架，库存500件，六档调节、有硅胶接触面。商品及包材成本21元，运费6元，平台费用先按5元估算。请帮我安排14天上市准备，推广预算不超过3000元。先梳理任务、分工和还缺哪些信息，不要实际上架或投放。

### 预置助手回复

已建立上市任务，先把目标、分工和边界对齐。

**目标**：围绕79元折叠电脑支架，交付14天上市准备资料，并建立可复核的经营观察口径。库存500件，初始预算上限3000元；单件费用暂按21＋6＋5＝32元计算。

**六位Agent分工**
- 王明：拆解8项任务、管理边界、向商家追问缺失信息。
- 李研：制定14天上市计划，接收后续预算变更。
- 周理：整理资料与交付目录，制作可评审的构图示意。
- 陈书：编写商品标题和详情文案。
- 刘市：核算预算、定义有效订单和观察指标。
- 赵审：复核实际采用的文案、预算和计划版本。

**本轮交付**：《上市任务书》v1。任务详情页已列出分工、交接关系与阶段验收要求。

**需要你补充**：重量、尺寸、适配范围、承重实测，以及真实商品图。缺失参数不会编造，也不会直接执行上架或投放。
