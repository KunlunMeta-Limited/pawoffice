# 会员登录与会话安全升级 · 交付说明 v2.3

> 文档性质：演示用业务成果。所有数字、测试及人员均为虚构 fixture，不代表真实系统运行结果。

## 1. 本轮目标

本轮将登录模块从单端登录补全为支持 **密码登录、短信验证、刷新令牌、主动退出和异常审计** 的会话链路。主要目标是降低登录接口延迟并补全风险验证，不以“代码完成”代替“验收通过”。

## 2. 已交付范围

| 范围 | 本轮状态 | 说明 |
| --- | --- | --- |
| 密码登录与错误提示 | 已实现 | 密码错误仅给统一提示；不暴露账号是否存在 |
| 短信验证码登录 | 已实现，限制策略未通过验收 | 接口已接入，但并发压力下存在单用户限流绕过 |
| 令牌续期与退出 | 已实现，需修复多端退出 | 刷新令牌轮换正常；部分多设备退出场景存在延迟 |
| 关键事件审计 | 已实现 | 记录登录成功、失败及频繁请求事件；敏感凭据不记录 |
| 正式发布 | 未启动 | 仅灰度环境具备访问能力，不代表生产环境上线 |

## 3. 主要交互要求

1. 密码登录失败时显示非枚举式错误提示，禁止回显敏感凭据。
2. 验证码有效期 5 分钟；同一手机号和 IP 维度的频率控制必须分别生效。
3. 退出登录清理客户端会话；其他终端会话按发布策略撤销。
4. 令牌续期异常时需跳转重新登录，不可陷入无限重试。

## 4. 验证现状

回归计划 120 条：114 通过、2 未通过、4 待复核，通过率 **95.0%**；目标 **98%**，尚未达标。当前灰度环境运行正常，但这不能证明正式发布条件已满足。

## 5. 未决事项与上线门槛

- **P0**：短信验证码并发限流绕过，修复后需要重做专项安全测试。
- **P1**：跨终端退出登录生效时间不稳定，需完成一致性修复与回归。
- **待复核**：移动端无障碍、弱网和旧版需求说明范围检查。

**结论：** 当前成果状态应为“已交付，尚未最终验证”。不得展示“已上线”或“已验收通过”。
