# PawOffice 成果阅读器 · 复审与交互规格

本轮依据独立视觉审核修订开发演示。交付型与说明型使用同一个阅读页框，共用顶部品牌、导航、外框宽度、内边距和页面滚动。交付型保留结论优先的首屏和文件行，说明型使用较窄的正文列，标题下只强调主要判断。用户可通过页框右上角在两份样例之间切换。

| 审核项 | 修订与证据 |
| --- | --- |
| P1-01 文档表格 | 带语义表头的 Markdown 表格使用浅色表头、单元格间距与行列分隔。文档正文最大宽度 820px。窄屏保留字体和列宽，横向滚动限制在可聚焦的表格容器。见 `03-markdown-table.png`、`12-mobile-document.png`。 |
| P1-02 CSV | 弹窗高度随内容变化，六行样例在 1440 × 900 视口实测 640px 高。单页简表省略分页器。筛选限定已载入行，保留表格和源文。见 `04-csv-six-rows.png` 至 `06-csv-source.png`。 |
| P1-03 阅读器外壳 | 使用同一页框渲染两份经 Schema 校验的 JSON。说明型直接显示结论与依据，交付型在首屏之后显示文件。见 `01-delivery-desktop.png`、`02-fact-desktop.png`。 |
| P1-04 发布范围 | 已有版本说明指明受控灰度环境。演示时间线显式显示“已发布至受控灰度环境”，协议中的 `released` 保持原值。见 `08-version-scope.png`。 |
| P2 可读性 | 交付物行增加版本与次级信息间距。关闭风险保留完整正文对比度。图廊提供“放大查看”。二进制变更显示“无法文本预览”。见 `07-diff-expanded.png`、`09-gallery-action.png`、`10-review.png`。 |

## 交互规则

| 对象 | 操作与反馈 |
| --- | --- |
| 交付物 | 阅读动作打开对应版本的预览。关闭按钮或 Escape 关闭预览，焦点回到触发按钮。复制按该文件原文操作，成功时显示“已复制”。下载该版本按原件字节保存。 |
| 文档 | 正文在窗口内部竖向滚动。宽表格内部横向滚动，外部正文维持阅读宽度。 |
| CSV | “表格 / 源文”切换视图，回到表格后保留筛选。筛选、表头和分隔符变化回到第一页。超过一页才显示页码和前后页按钮。原文和下载保留源值。大表有独立滚动区。 |
| 代码差异 | 文本文件行可用鼠标、Enter 或 Space 展开。再次激活或按 Escape 收起。二进制行展示文件路径及说明，没有展开控件。 |
| 图廊 | “放大查看”在新窗口打开原图，保留图片比例。 |
| 完整记录 | 两种样例均可从同一个页框打开完整记录，关闭完整记录后回到对应样例。 |

## 实际浏览器核对

- Chromium 中打开两份 JSON 对应页面，确认说明型无空交付区。
- 打开 Markdown 文件，核对复制内容与下载字节等于样例原文。按 Escape 后确认焦点回到阅读按钮。
- CSV 六行缩至匹配一行，表头开关生效。切换源文与下载均核对原文，再切回表格保留筛选。另在浏览器内临时注入 70 行合成数据，验证内部滚动和第二页从第 26 条开始。
- 用 Enter 与鼠标分别展开差异，核对首个增删行的行号与文本，再用 Escape 与鼠标收起。图廊按钮实际打开竖版原图。
- 1440、1280、390、360、320px 下展开补充内容，文档滚动宽度与视口一致。320 和 360px 追加 125% CSS 缩放模拟，页面宽度同样没有横向溢出。真实系统字号设置仍需在目标设备上复核。
- 390px 的完整阅读路径见 `11-mobile-390-full.png`，包含所有交付物、检查与风险。截图记录当前开发演示状态，审核通过后再确定 DSH 接入范围。
