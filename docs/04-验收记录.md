## 2. 本轮代码修复

1. Provider overload/rate limit 最多一次重试，避免单回合放大为四次上游请求。
2. Host 错误细分为 rate limit、overload、server error、timeout、protocol error，并透传 retryable。
3. `prompt_async` 返回 `OpenPaw-Turn-ID`；Gateway 202 回应携带 turnID；Controller 立即绑定准确回合。
4. 只在 `active_turn` 或旧协议 code 缺失的 409 时接管活动回合，`idempotency_conflict` 不再劫持其他 turn。
5. Gateway 按 `sessionId + requestID` 合并并发消息提交，并缓存完成确认 30 秒。
6. 回合失败、取消和重启异常以 system 正文持久显示。
7. 修复 Windows 测试随机端口命中 Fetch 禁用端口导致的偶发 `bad port`。
8. 回退 OpenPaw README 整篇翻译、纯 CLI 输出翻译、Sandbox 两处语义等价改写和历史日志删除；AI Office 标准 npm 命令恢复为 `vite/tsc/eslint/vitest`。
9. UI 布局、字体和 Canvas 本轮没有修改。
10. 修复 Host 幂等重放顺序：已接收的 `requestID` 在 Provider 凭据失效或 Host 重启后仍可返回原 `turnID`；新请求仍按 Provider 配置校验。
11. 修复 Host 强制关闭结果判定：以已登记任务最终是否全部收割为准，避免任务已清空却误报关闭失败。
