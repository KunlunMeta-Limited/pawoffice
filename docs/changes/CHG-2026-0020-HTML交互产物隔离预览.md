# CHG-2026-0020：HTML 交互产物隔离预览

## 先说结论

本变更为独立 HTML 产物增加通用的隔离“原页”模式，使任意完整网页按自身 CSS 和 JavaScript 在文件中心运行；同时提供不执行脚本、不继承作者样式的统一“阅读模式”和源码模式。HTML 查看器不再识别或重建地图，地图、仪表盘、报告和其他网页使用同一条渲染链路。原页 iframe 只授予脚本权限，不授予同源、表单、弹窗、下载或顶层导航权限。

**当前状态：实施中（implementing），待本轮视觉层级与文件对话框回归。** 用户于 2026-10-10 明确要求继续优化 HTML 整体显示，并禁止针对地图做特殊定制；随后进一步明确查看区域恢复原尺寸，重点修复 Markdown 正文、表格及 HTML 阅读模式的字体清晰度。根据真实页面截图，第二轮继续收敛 Markdown 正文、说明引用块与表格的字号关系，并让文件中心以有明确边界的对话框打开文件。

## 2. 变更原因

最新“游玩”对话生成的 HTML 本身包含完整 Leaflet 地图、多日路线切换、路线播放和地点详情，但现有预览器会删除全部脚本、事件属性和外部资源，并通过 CSP 禁止网络，因此只能展示静态外壳或由解析器重建的内部路线图，视觉与直接在浏览器打开不同。需要在不把模型 HTML 注入主文档的前提下提供接近原网页的展示能力。

## 3. 涉及仓库

只修改 `ai-office-react-main`。不修改 OpenPaw、Gateway、会话协议或文件存储。

## 5. 明确禁止范围

- 不使用 `dangerouslySetInnerHTML`，不把产物 HTML 放入 AI Office 主文档。
- 不为 iframe 增加 `allow-same-origin`、`allow-forms`、`allow-popups`、`allow-downloads` 或任何顶层导航权限。
- 不允许 `http:` 脚本、样式、图片或网络请求，不允许嵌套 iframe、object、embed、base 或 meta refresh。
- 不修改 `src/types/**`、`officeGatewayApi.ts`、Gateway、依赖和构建配置。
- 不把对话消息中的紧凑 HTML 代码块改为自动执行脚本。
- 不按地图变量、DOM 标识、文件名或业务内容为 HTML 增加专用解析和展示分支。

## 6. API 变化

不新增或修改 HTTP、SSE、Gateway API。`ArtifactHtmlPreview` 的既有 `html` 与 `compact` 属性保持兼容。

## 7. 字段变化

不涉及公共协议字段。组件内部查看模式为 `web`、`reader`、`source`，刷新计数只用于重新挂载 iframe。

## 8. 保护路径

`ArtifactHtmlPreview.tsx` 是不受信 HTML 的 L2 浏览器隔离边界。交互模式必须同时依赖 iframe sandbox 与注入 CSP，任何权限扩展需另行登记。

## 9. 影响、数据流和实现

```text
独立 HTML 文件（地图、报告、仪表盘、小游戏等一致）
  -> 删除嵌套浏览上下文、插件对象、base 和自动刷新
  -> 注入只允许 inline/HTTPS 脚本与样式、HTTPS/data/blob 媒体的 CSP
  -> sandbox="allow-scripts" 的 opaque-origin iframe
  -> 保留作者 CSS、字体和布局，页面自身交互运行但不能访问 AI Office 父页面

对话内 HTML 代码块
  -> 默认进入统一阅读模式，不执行脚本和网络

任意 HTML
  -> 可切换原页 / 阅读模式 / 源码
  -> 阅读模式移除作者脚本、事件、外链和样式，使用统一中文正文排版
  -> 原页失败时可重新加载或切换阅读模式，不按业务内容做降级解析
```

不采用 `allow-same-origin`，因为 `srcdoc` 同时拥有脚本与同源权限会削弱 iframe 隔离。外部资源只允许 HTTPS；本机 `http://127.0.0.1` 等地址被 CSP 阻断。

## 10. 验收测试

1. 组件测试验证独立 HTML 默认原页、`sandbox="allow-scripts"` 且没有 `allow-same-origin`，CSP 允许 HTTPS 并禁止表单、对象和嵌套页面。
2. 组件测试验证紧凑 HTML 默认阅读模式，脚本、事件和作者样式被删除，统一排版和严格 CSP 生效。
3. 组件测试验证包含地图结构的 HTML 不出现专用模式或解析分支。
4. Playwright 验证内联与 HTTPS 脚本实际执行、无法修改父页面、重新加载恢复初始状态，阅读模式和源码仍可切换。
5. 执行全量 Vitest、ESLint、TypeScript/Vite build 和治理检查；使用隔离 E2E 端口，不启动正式 5173/8765/4096 服务。
6. 真实浏览器验证 Markdown 正文为 16px、表格为 14px、代码不再二次缩小；窄屏表格必须保持字号并在自身容器横向滚动。
7. HTML 阅读模式正文为 16px、表格为 14px；独立 HTML 查看器恢复 18px 外层留白、边框和圆角，不以全铺满视口掩盖排版问题。
8. 第二轮视觉验收中 Markdown 正文调整为 15px、说明引用块为 14px、表格为 15px，表格文字不得弱于周边说明；标题按同一比例回收。
9. 文件中心打开文件时显示居中的有界对话框和背景层，右侧文件列表继续可见；关闭按钮、Escape 和点击对话框外区域都能退出查看。

## 11. 追踪、兼容和回滚

旧调用方无需改动。独立文件默认模式从内部路线地图或静态预览改为交互网页；对话紧凑预览保持原安全默认。回滚时可先把默认模式恢复，再删除交互 iframe 与 CSP 生成器，不影响文件内容、会话记录或内部路线地图。
