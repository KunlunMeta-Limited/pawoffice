# CHG-2026-0017：HTML 与地图产物展示稳定性

## 先说结论

本变更已按用户本轮授权完成实现和验证：HTML 在无授权 sandbox iframe 中静态预览，HTML 内嵌静态路线可在不执行脚本的前提下转为可信地图，地图补齐路线选择、地点属性、里程、分类打卡点、动态行进和详情。解析器支持标准 GeoJSON、点位对象数组和独立坐标路线数组，且只在评分真实存在时展示评分。当前状态为已验证，不改变办公室比例、Gateway 文件安全边界或 OpenPaw 核心逻辑。

## 2. 变更原因

网关已经能识别 HTML，但文件中心和产物查看器只显示源码；对话中的 HTML 围栏代码也不能预览。首轮静态预览会按安全规则移除脚本，因此依赖 Leaflet CDN 和 JavaScript 数组初始化的旅游路线页面只能显示外壳。地图已有基础格式支持，但 CSV 丢弃地点属性，KML/GPX 缺描述、海拔和时间，界面没有里程、编号点位和选中地点详情。用户要求完成这些展示链并执行稳定性测试。

## 9. 影响、数据流和实现

```text
HTML 围栏 / HTML 文件 / HTML 产物
  -> Acorn AST（仅 Literal / Array / Object / 无插值模板 / 数字正负号）
  -> 标准 data-ai-office-map GeoJSON 或静态路线/点位数组
  -> 可信 React + Leaflet 路线地图
  -> 不支持的动态表达式直接忽略，不 eval、不执行脚本
  -> 同时保留以下安全静态预览链路
  -> DOM 清理（脚本、表单、框架、事件、外部 URL）
  -> CSP
  -> 无授权 sandbox iframe 预览 / React 转义源码

GeoJSON / CSV / TSV / KML / GPX / HTML 静态路线
  -> 坐标校验、属性保留、格式归一
  -> 去重地点、路线数和球面里程
  -> Leaflet 单路线选择、编号点位、四向说明卡、分类打卡点、地点详情和三种底图

普通 JSON POI/路线数组或 `pois/points/places/locations/routes/items/data` 外壳
  -> 排除图表和普通配置对象
  -> 复用静态点位/路线归一逻辑
  -> 地图；无法识别为地图时进入统一格式化 JSON 预览

路线播放按钮
  -> 独立动画层，不重建 Leaflet 地图
  -> 移动标记 + 航向 + 已行进轨迹 + 进度
  -> 停止、切换路线或卸载时取消 animation frame 并移除动画图层
```

HTML 静态预览允许内联样式和 `data:` 媒体，不允许脚本、表单、对象、嵌套框架、导航和网络连接。HTML 地图提取器只接受有节点预算和深度限制的静态字面量，函数调用、成员访问、展开、计算属性和其他动态表达式均不执行。地图不调用地理编码服务，只展示文件中已有坐标和属性，避免地址误判与隐式位置请求。

## 11. 追踪、兼容和回滚

真实旅游 HTML 原先依赖 Leaflet CDN、在线瓦片和 JavaScript 静态数组；安全预览禁止脚本后无法初始化。当前实现读取 AST 静态数据并交给可信地图组件，不放宽 iframe 权限。解析不依赖 `DAYS`、`POIS`、`ROUTES` 等变量名：点位按经纬度字段识别，路线按对象中的点位序列或 `coords/coordinates/path/polyline` 坐标序列识别。普通点位集合不会被误连成路线，点位自身分组会被保留，有序路线保留原始颜色。路线按钮默认只展示第一条路线，独立 POI 可切换；永久说明卡按站点顺序循环使用右、下、左、上四个方向，降低密集点位和重复坐标的遮挡。回滚可以独立撤回 HTML 地图提取和查看模式；不影响 Gateway 或 OpenPaw 会话事实。

卫星和街道瓦片仍依赖外部服务，失败时保留“仅路线”。HTML 静态预览会移除交互能力，但源码视图保留原文；这是安全兼容取舍。
