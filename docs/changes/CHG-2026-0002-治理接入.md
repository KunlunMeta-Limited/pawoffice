## 9. 影响、数据流和实现

### 影响分析

本次只增加治理文件，不改变 Vite 产物、Gateway 行为或浏览器请求。新增设计基线冻结动作联合类型、路由、文件根边界、FIFO、失败隔离和面板状态；profile、check.py、CI、CODEOWNER 将其转成机器检查和人工责任。扩展产品能力的范围判断留给后续 CHG。

### 数据流和失败路径

```text
需求/设计 -> AI 起草 draft CHG -> 人工审核 -> approve -> AI 受控编码
                                      -> Git diff -> CI + CODEOWNER -> 合并
```

Gateway 非法批次、越界文件和未登记路由必须阻断；动作投影失败不影响 Host 回合；AI 发现需改未列文件必须停止更新 CHG。

### 实现方案和选择理由

使用中文 Markdown CHG 作为人和工具的唯一事实源，避免审批人阅读 TOML 字段；profile 只登记项目路径/命令；Schema 提供机器契约；CI 阻断实际越界；CODEOWNER 提供身份和责任。首次接入不修业务注释，保证不引入行为变化。
