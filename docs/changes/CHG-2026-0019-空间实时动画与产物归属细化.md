# CHG-2026-0019：空间实时动画与产物归属细化

## 先说结论

本变更修复三个用户可见问题：未挂载空间会在稍后打开时补播过期动画；主空间仍可能吸收子空间文件；产物列表没有按内容分类且直接暴露扩展名。同时让空间总览卡片空白区域可直接进入对应空间。变更不实施可靠动画 v2，不新增协议、依赖或文件系统写入点。

**当前状态：已批准（approved），实现与自动化验收完成。** 用户于 2026-10-09 明确要求执行修改并使用汕尾 7 天多 Agent 旅行规划进行验证。真实 Provider 旅行任务需要正式服务运行；本轮遵照用户“不代为启动”的要求，未启动正式服务，也未用 mock 冒充真实任务结果。

## 2. 变更原因

1. `officeSceneBridge` 在场景未挂载或视觉暂停时缓存全部拜访和状态动作，之后打开子空间才按 FIFO 从头补播；动画时间轴因此晚于真实对话。
2. 主空间产物扫描会把最终答复提到的子空间登记文件再次提升到主空间，造成同一文件跨空间归属；最终交付和子 Agent 过程资料边界不够严格。
3. 产物货架按文件平铺并显示完整扩展名，用户无法快速区分规划文档、互动地图、路线数据、核验清单和可视化。
4. 空间总览只有窄标题按钮可进入空间，点击卡片办公室空白区域没有反应。

## 4. 明确禁止范围

- 不修改 `src/types/**`、`officeGatewayApi.ts`、动作协议、依赖、构建配置或 OpenPaw 源码。
- 不实现 ACK、持久 journal、消费者 lease 或可靠动画 v2；动画仍是可降级投影。
- 不执行模型生成脚本，不显示 reasoning、工具输入输出或敏感路径。
- 不按 mtime 猜测会话归属，不移动或复制真实文件来伪造主空间交付。

## 5. API 与字段

HTTP 路由和字段不变。产物响应继续返回真实 `path/name/kind/mimeType`；无扩展名名称和分类仅在共享 UI 展示层计算。指定子空间只返回该空间登记文件；主空间只返回主 Agent 成功写入、实际存在且最终答复明确作为交付列出的文件。

## 6. 数据流与实现

```text
实时动作 -> 已挂载可见场景 -> 立即播放
        -> 未挂载/暂停场景 -> 丢弃已错过的拜访；每个角色只保留最新状态
        -> 场景恢复 -> 直接呈现最新真实状态，不补播历史

子 Agent 写文件 -> register_artifact(workspaceId) -> 仅对应子空间货架
主 Agent 写文件 -> transcript 成功工具 + 最终交付语义 -> 仅我的空间
真实 path/kind -> 展示层内容识别 -> 分类分组 + 无扩展名标题
```

替代方案是后台常驻每个 Pixi/Spine 场景，但会按空间倍增 WebGL、纹理和角色开销，且隐藏 Canvas 仍可能节流；本变更采用逻辑状态收敛，符合动画可降级边界。
