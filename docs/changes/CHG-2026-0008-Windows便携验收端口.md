## 2. 变更原因

历史 Windows 主机把 TCP 4097 至 4296 保留，Playwright 临时 Vite 默认端口 4173 启动返回 `EACCES`，导致新电脑无法直接执行浏览器验收。该问题与产品运行时无关，但会让标准 E2E 门禁无法启动。

## 9. 影响、数据流和实现

### 影响分析

仅 Playwright 启动的临时 Vite 默认端口变化。正式 5173、8765、4096 不受影响，环境变量 `OFFICE_E2E_VITE_PORT` 继续具有优先级。测试仍不得复用已存在服务，以避免旧环境变量或残留进程造成数据污染和假通过。

### 数据流和失败路径

```text
npm run test:e2e -> Playwright 配置读取 OFFICE_E2E_VITE_PORT
                 -> 未设置时使用 4397
                 -> 启动隔离 Vite -> 浏览器测试
端口占用或无权限 -> 启动失败并返回非零，不复用未知服务
```

### 实现方案和选择理由

选择一个已验证可绑定且不在已知 Windows 保留范围内的默认端口，同时保留环境变量覆盖，以兼顾开箱验收和不同机器的冲突处理。没有修改生产端口，因为缺陷只发生在测试临时服务。
