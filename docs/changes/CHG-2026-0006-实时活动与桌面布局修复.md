# CHG-2026-0006：实时活动、桌面布局与切页恢复修复

## 先说结论

本变更修复桌面端对话面板挤压办公室场景、切页恢复期间状态误报，以及短工具回合缺少实时活动提示的问题。它为会话状态增加脱敏活动摘要，调整前端状态恢复和桌面布局，并提供轻量 Markdown 展示。它不保存工具参数、文件正文或思考正文，也不把办公室角色变成独立智能体。

## 2. 变更原因

真实联调发现三个问题：桌面端对话右栏使用可增长 flex，挤压办公室场景；引擎回合期间消息读取可能等待锁，切回对话中心时短暂显示读取失败或缺少处理中提示；工具回合很短时，前端只看到结束后的整理状态，无法知道正在搜索、读文件还是写文件。若不修改，用户会把布局压缩、短暂读取失败和缺失活动提示误认为会话丢失或模型停止。

## 9. 影响、数据流和实现

### 影响分析

前端布局、对话状态轮询、公共 TypeScript 类型和 Host 状态响应受到影响。活动摘要仅存在于 Host 内存，不新增持久字段，不改变会话 JSONL。状态和消息分开读取，消息接口等待时不再把正常活动误报为历史损坏。轻量 Markdown 只处理标题、列表、加粗和行内代码，不执行 HTML。

### 数据流和失败路径

```text
AgentLoop/工具事件 -> Host SessionActivity(kind/tool/task)
                  -> GET /session/status
                  -> Gateway 目标会话状态代理
                  -> React 状态条 -> 办公室角色阶段投影
Host message -> conversationViewStore -> 对话气泡
状态成功但消息暂不可读 -> 保留活动状态和已有消息，不伪造读取失败
```

工具名映射到对应办公室角色；工具和 reasoning 不进入历史气泡。接口失败只影响状态展示，不得修改 Host 回合结果。

### 实现方案和选择理由

采用内存级、字段白名单化摘要，避免完整工具事件进入浏览器；采用状态与消息独立读取，让切页恢复先显示真实执行阶段；固定右栏宽度，使办公室场景和对话区域拥有稳定边界。
