# 旅游规划综合演示提示词

## 关键词

多 Agent 复用、真实旅游调研、WGS84、路线切换、动态地图、地点详情、预算图表、Mermaid、来源核验、产物回读。

## 精简提示词

请为“从 `{出发地}` 前往 `{目的地}` 的 `{天数}` 天旅行”制定可执行方案。出行日期 `{出行日期}`，偏好 `{偏好}`，预算 `{预算}`。请复用职责相近的子 Agent，并按需分工完成交通地理、住宿餐饮、景点节奏和文档可视化；不要重复创建同类 Agent。

必须在工作区生成并实际回读：

- 一份 Markdown 攻略，包含逐日安排、交通、住宿、餐饮、预算、预约、风险和替代方案；
- 一份 WGS84 GeoJSON 和一份 HTML 互动地图，默认只显示路线 1，可切换每日路线、播放/停止行进并查看地点详情；
- 一份 POI CSV，以及预算 3D 柱状图、时长对比图、预算构成图；
- 旅行流程图、Agent 关系图、数据流图和产物索引。

## 验收规则

1. 地点名称、地址和坐标优先用两个公开来源核验；无法确认则标记“待核验”，不得进入地图几何。
2. 最终坐标统一为 WGS84；GCJ-02、BD-09 必须转换并保留原坐标系。没有可信道路轨迹时明确标记“示意连线”。
3. 评分、评价数、营业时间、价格和照片必须附来源 URL 与采集日期；无法核实时留空，禁止编造。
4. GeoJSON 的 Point `group` 必须与路线 `routeName` 一致；HTML 同时嵌入 `data-ai-office-map` 静态 GeoJSON，不能依赖执行不受信脚本才能展示。
5. 禁止生成临时脚本和一次性转换程序；每个子 Agent 只保存必要正式产物。
6. 完成后在 AI Office 重新打开所有产物，验证路线数量、切换、播放、停止、照片、来源、JSON 地图、图表和 Mermaid；只报告真实通过项与待人工确认项。
