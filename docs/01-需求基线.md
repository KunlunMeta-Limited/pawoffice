更新日期：2026-09-17

本文把 `D:/workSpace/KunlunMeta_Git/master-plan.md`、后续用户可靠性要求和当前实现统一为可验收基线。`已编码` 仅表示代码存在，`已验证` 表示当前工作树已有实际命令或旅程证据，`阻断` 表示完整发布条件仍不成立。

## 1. 系统边界

1. Windows native 主链路为 `React :5173 -> Action Gateway :8765 -> openpaw-engine-host :4096 -> AgentLoop/Provider`。
2. OpenPaw 通用 CLI/Core 必须能脱离 AI Office 独立运行；`engine-host` 是默认关闭的可选 feature。
3. 通用 Host 默认绑定 `127.0.0.1:0`，native 启动脚本显式固定 `4096`；Gateway 固定 `8765`，Web 固定 `5173`。
4. Host 是 session JSONL 的唯一写入者。Gateway 和 React 只通过 HTTP 读取或提交，不直接写会话事实。
5. 同一 session 同时最多一个活动回合；不同 session 可以并行，全局调度默认 4 个运行、32 个排队。
6. 动画是可降级视觉投影，失败不得改变 Provider、工具、任务或回合终态。
7. Host 业务代码、Host tests、原工程 tests+xtask 必须分别不超过 5000、1500、10000 行。
8. UI 当前冻结。本轮只修复对话可靠性、测试稳定性、最小变更和文档，不调整布局、字号或 Canvas。
