# PawOffice 8 个演示场景 · 成果阅读页验收包

本包用于把「8 个演示任务跑完后生成的成果阅读页」交给评审（ChatGPT / 人工）审核。
所有截图来自**实际运行的生产前端组件**（`WhiteboardReader → ResultReaderDialog → ResultWorkspace`），
不是设计稿或手绘图。

## 1. 怎么看（复现方式）

1. 启动前端（仓库根目录）：`npm run dev`（dev）或 `npm run build && npm run preview`（生产构建）
2. 打开任一场景：`/?office-frame=local:<scenario-id>`
3. 点工具栏 ▶「开始演示」；电商运营团队需在决策卡出现时点「确认上架」
4. 等 15–25 秒任务完成，工具栏出现「当前成果 · 已交付」，点开即为本包截图页面

## 4. 数据来源与真实性

- 所有成果都来自前端**本地演示数据**，不连接真实业务系统、不产生真实操作；
- 演示脚本完成任务后，`demoResults.ts` 按该场景的任务语义生成结构化 `OfficeResult`，
  经冻结的 `packages/protocol` schema 校验后写入白板；
- 页面上的「模拟数据」提示、待处理检查、开放风险和结论边界均保留，不把未验证信息写成结论
  （例如报税场景明确「凭证补齐前不提交申报」，并保留 1 项待处理检查）。

## 5. 已知边界（审核时请视为范围外）

- 8 个演示均无历史交付（deliveries）与版本记录，因此成果页不出现版本时间线；
- 演示数据不触发真实后端、不包含移动端截图（移动端另有专项验收记录）；
- 本包只覆盖「演示任务 → 成果页」的语义与视觉映射，不覆盖真实后端返回的任意结果数据；
- 截图取自 dev server 的同一套生产组件链（与生产构建一致），生产构建已重新构建并通过浏览器冒烟。
