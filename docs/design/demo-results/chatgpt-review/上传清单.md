# 上传清单（给 ChatGPT）

## 推荐：上传打包文件（最少操作）

上传根目录的 **`PawOffice_8个演示成果阅读页_ChatGPT审核包.zip`** 即可，包内已包含：

| 文件 | 作用 |
|---|---|
| `chatgpt-review/PROMPT.md` | 审核提示词（先让 ChatGPT 读这个） |
| `README.md` | 场景→成果映射、复现方式、范围边界 |
| `screenshots/01…08-*.png` | 8 张成果页首屏截图 |
| `capture-manifest.json` | 截图生成信息（含 console 错误数） |
| `data/<scenario-id>.json` | 8 份成果数据 |
| `data/index.json` | 8 个场景的成果摘要索引 |
| `code/demoScenarios.ts`、`code/demoReports.ts`、`code/demoResults.ts` | 演示语义与成果映射源码 |

## 如果 ChatGPT 有文件数量/大小限制

按顺序上传（最少可以只传 1–3 项）：

1. `chatgpt-review/PROMPT.md`
2. `README.md`
3. `screenshots/` 全部 8 张
4. `data/index.json` + 任意 2–3 个 `data/*.json` 样例
5. `code/` 三个文件（可选，用于核对语义映射）

## 建议提问方式

把 `PROMPT.md` 内容作为第一条消息发出，并附上 zip；再说一句：

> 请按 PROMPT 的六个维度逐一审核这 8 个演示场景的成果页，输出评分表、问题清单和是否可进入下一轮的结论。
