## 二、操作顺序

1. 新开一个 ChatGPT 对话（不要续旧对话）。
2. 先上传批次 A，再上传批次 B（或一次性 20 个）。
3. 发送 `PROMPT-审核提示词.md` 里的「提示词正文」整段。本轮 prompt 新增「第 5 层 · 数据类型专用视觉体系」与「数据类型映射评价表」输出要求。
4. 如果它只评论样式，追问：`请按 07 的映射表逐类判断“是否只是同一模板换字”，并给出 type-01…type-08 的具体证据。`
5. 如果它建议改协议/加字段/换库，提醒：`红线：协议层冻结、仅前端、不新增依赖；请放入“需协议支持（本次不做）”。`

## 六、本轮审核必须核对的 5 个事实

1. 每类数据有专用形态，不是同一模板换字：`type-01`（6 metric）、`type-03`（4 artifact）、`type-04`（审查带/风险登记）、`type-05`（版本时间线）、`type-06`（行内 diff）。
2. 两种阅读重心：`type-07` 无「本轮交付」且正文前置；`02/03` 真实样例交付优先；由 `data-reading-mode` 派生、无协议字段。
3. 交付/文档同源：`type-02` 中 `documents` 三项与 artifacts 精确同源，指向同一预览入口，不重复整卡。
4. 不变量：协议零改动（PART-B git 证明）、无 Tab、Section 源顺序、历史交付与安全回退保留、无新依赖。
5. 证据：17 张真实浏览器截图 + `tests/resultTypeVisual.test.mjs` 8 项类型测试 + 既有 80 项结果测试，tsc/eslint/build 均 exit 0（03 报告）。
