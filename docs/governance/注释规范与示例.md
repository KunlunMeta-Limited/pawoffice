## 公共类型或字段

```typescript
/**
 * 功能：描述由 OpenPaw Host 投影到场景的角色状态动作。
 * 字段语义：`rosterNo` 定位 1 至 6 号角色，`state` 为固定状态枚举，`task` 是脱敏摘要。
 * 数据来源：Host 的 `office.rs` 或 Gateway 内部状态。
 * 数据去向：`officeActionHttp`、`officeActionDispatcher` 和 Pixi 场景。
 * 约束：必须至少提供 `rosterNo` 或 `agentId`；未知状态拒绝，不得静默猜测。
 * 稳定性：跨项目公共契约，修改必须建立 CHG 和 Schema diff。
 * 关联：`DAT-OFFICE-ACTION-001`。
 */
export interface OfficeActionSetState {
  type: 'set_state';
  rosterNo?: number;
  agentId?: string;
  state: AgentState;
  task?: string;
}
```

模块顶部使用 `/** ... */` 或 `//!` 说明职责和边界；复杂内部逻辑使用中文解释不变量、失败和取消原则。不要求给每一行代码写解释性注释。
