# AI Office / OpenPaw 测试大纲

更新日期：2026-09-18

目标：对同一冻结候选执行单元、契约、功能、系统、压力、破坏性、视觉和发布验收。历史绿测、skip、mock、测试源码存在或单次复跑都不能替代对应门禁。

## 1. 执行原则

1. 记录两个仓库 commit、工作树 diff、依赖锁、二进制 SHA-256、源码指纹和运行配置。
2. 自动化使用随机端口和隔离临时目录，不停止或复用用户的 4096/8765/5173 服务。
3. 修复先复现原缺陷，再跑定向回归，再跑受影响全量。
4. 对话串线、正文损坏、重复终态、永久 busy 和未授权路径读写的错误预算为零。
5. Provider smoke 只验证真实接入，不替代 mock 的确定性故障矩阵。
6. UI 冻结期间继续做视觉回归，但缺陷只记录，不混入可靠性修复提交。
