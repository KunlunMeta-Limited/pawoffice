# PawOffice Brand Assets

- `logo.png`: the existing transparent mascot head, used for application and browser icons.
- `icon.png`: the 128 × 128 mascot icon used for the browser touch icon, classroom page and farm branding.
- `title.png`: transparent mascot and **PawOffice** wordmark, used by the office sidebar.

The wordmark was updated with the built-in ImageGen tool on 2026-10-19. The mascot identity, horizontal layout, rounded lettering and charcoal color were preserved. The image has genuine alpha transparency and a 2172 × 724 canvas.
